# Web9000 差勤查詢系統改版規格書

## 程式目的
將舊有的差勤查詢系統改版並增加新的功能，使用 ASP.NET Core Razor Pages (C#) 開發。
SQL Server 資料庫有 2 個：
1. **gdtek**：差勤打卡系統使用的 DB
2. **WEB9000**：查詢系統管理登入使用者與其他設定用的 DB
*註：資料庫連線設定設定在 json 設定檔中。*

## 功能頁面說明

### 1. 登入首頁
* **畫面**：公司 Logo 檔案名稱與公司資訊設定在 json 設定檔中，方便動態調整。
* **功能**：提供使用者登入。密碼欄位按下 ENTER 或按下「登入」按鈕後，檢查帳號、密碼是否有輸入，並驗證帳號密碼的正確性。驗證無誤導入「紀錄查詢」功能頁面。

### 2. 主畫面區域配置
所有功能頁面分成三個區域：
* **左側 (主功能區)**：依照使用者的權限列出可使用的功能。
  * **一般使用者**：可使用「紀錄查詢」、「日報表」、「月報表」、「修改密碼」、「登出」5 個功能。
  * **管理者**：可額外使用「使用者管理」、「部門管理」2 個功能。
* **右側上方**：資料編輯區。
* **右側下方**：資料列表區。

### 3. 紀錄查詢
* **功能**：
  * 「部門」：下拉選項，列出部門資料。一般使用者只列出所屬部門及可管理部門；管理者列出所有部門，預設為「請選擇」。
  * 「員工」：下拉選項，列出所屬選取部門的員工。一般使用者只列出自己，若有管理權限則列出該部門所有成員；管理者列出選擇部門的所有成員。預設為「全體員工」。
  * 「日期(起/迄)」：日期挑選控制項，預設為今日。
  * 「查詢」按鈕：檢查是否有選取員工，日期起需 <= 日期迄，無誤後列出資料。
  * 「報表」按鈕：檢查條件無誤後，匯出指定日期的差勤資料，檔案格式為 `xlsx`。
  * **資料分頁**：採分頁方式，一次列出的筆數可在 json 檔案中維護。

### 4. 使用者管理
* **功能**：
  * 唯讀欄位：「員工編號」、「員工姓名」。
  * 「部門」：列出部門資料，預設「請選擇」。
  * 「登入帳號」/「登入密碼」/「確認密碼」。
  * 「權限」：下拉選項（請選擇、一般使用者、系統管理者）。
  * 「儲存」按鈕：檢查必填與密碼一致性、帳號是否重複後更新資料庫（此功能僅更新，無新增）。
  * 「刪除」按鈕：提示「確定要刪除資料嗎？」，確認後刪除勾選資料。
  * 「匯入」按鈕：將來源資料庫的員工匯入。員工編號不存在則新增（預設密碼為工號）；存在則僅更新 `EMPLOYEE_NAME`, `CARD_NO` 2 個欄位。
  * 「查詢」功能：輸入文字後，搜尋員工編號或姓名。
  * **管理部門設定**：列表最後有按鈕可開啟視窗設定員工可管理的部門，更新至 `W9K_MANAGER`。
  * **資料分頁**：採分頁方式，筆數由 json 維護。

### 5. 部門管理
* **功能**：
  * 「部門名稱」：顯示列表選取資料的名稱。
  * 「新增」按鈕：清空部門名稱，呈現未選取狀態。
  * 「儲存」按鈕：檢查輸入與是否重複後，新增或更新資料庫。
  * 「刪除」按鈕：提示「確定要刪除資料嗎？」，確認後刪除勾選資料。
  * **資料分頁**：採分頁方式，筆數由 json 維護。

### 6. 日報表
* **功能**：
  * 「日期」：日期挑選控制項，預設今日。
  * 「匯出」按鈕：匯出指定日期差勤資料（僅讀取 `EventAlarmCode` = '正常'），格式 `xlsx`。
  * **報表格式**：
    * 第 1 列：日報表
    * 第 2 列：日期、匯出人員
    * 第 3 列：標題（工號、部門、姓名、簽到進-1、簽到進-2、簽到出-2、簽到出、上班時數、備註）
    * 資料邏輯：
      * 簽到進-1：當日第 1 筆
      * 簽到進-2：筆數 > 3 時，倒數第 3 筆
      * 簽到出-2：筆數 > 2 時，倒數第 2 筆
      * 簽到出：筆數 > 1 時，最後 1 筆
      * 上班時數：簽到出 - 簽到進-1（小時:分鐘）

### 7. 月報表
* **功能**：
  * 「年度」/「月份」：下拉選項，預設系統年月。
  * 「部門」/「員工」：下拉選項連動，預設全體員工。
  * 「匯出」按鈕：匯出指定條件差勤資料（僅讀取 `EventAlarmCode` = '正常'），格式 `xlsx`。每個員工 1 個 Sheet。
  * **報表格式**：
    * 第 1 列：報表年月、列印日期
    * 第 2 列：編號、姓名、部門
    * 第 3 列：標題（日期、上班、簽到進-2、簽到出-2、下班、上班時數、時數審核、備註）
    * 資料邏輯：
      * 上班：當日第 1 筆
      * 下班：最後 1 筆

### 8. 密碼修改
* **功能**：
  * 「原始密碼」、「新密碼」、「確認密碼」：預設空值。
  * 「儲存」按鈕：檢查原始密碼正確性及新密碼一致性後，更新資料庫。

### 9. 登出
* **功能**：登出系統，回到登入頁面。
